=====================================================
TOPOGUESSER - Kampagnen-Ordner (docs/campaigns/)
=====================================================

Hier können neue Kampagnen auch im fertig kompilierten Build 
direkt hinzugefügt werden - ganz ohne Neukompilierung!

SO GEHT'S:
1. Erstelle eine Kampagne im Topoguesser (Creator-Modus) und klicke auf "Download"
   -> Du erhältst eine Datei wie z.B. "meine-runde.campaign.json"

2. Kopiere die Datei einfach hier in diesen Ordner "docs/campaigns/".

3. Öffne die Datei "docs/campaigns/index.json" und füge den Dateinamen hinzu:
   [
     "salzkammergut-playtest.campaign.json",
     "alpen-klassiker.campaign.json",
     "meine-runde.campaign.json"
   ]

4. Fertig! Sobald Topoguesser im Browser aufgerufen oder neu geladen wird,
   erscheint die neue Kampagne automatisch auf dem Start-Screen.
